# persona-chat — ダイエット疑似コーチチャット

ダイエットサポートの「疑似コーチ」チャットアプリです。サポート生さんが食事の写真やメッセージを送ると、コーチのペルソナ（口調・視点）を再現したAIが「良かった点 → さらに良くする提案」の形でフィードバックします。

3ヶ月の集中サポート期間が終わった後も、高額会員の方に対して**これまでと変わらない伴走を疑似的に継続する**ことを目的にしています。

## 特長

- 📷 **食事写真のフィードバック** — Claude の画像認識（vision）で写真を見て、実際のコーチのように具体的にコメント
- 💬 **LINE風のチャットUI** — スマホから使いやすいモバイルファースト設計
- 🧑‍🏫 **コーチのペルソナ再現** — 「褒める → 具体的な改善提案 → 励まし」の型を徹底（`lib/persona.ts` で自由に調整可能）
- ⚡ **リアルタイム応答** — ストリーミングで返答が少しずつ表示される

## 技術構成

- Next.js (App Router) / TypeScript / React
- Anthropic Claude API（モデル: `claude-opus-4-8`、vision + streaming）
- API キーはサーバーサイド（API ルート）でのみ使用し、ブラウザには露出しません

## セットアップ

```bash
# 1. 依存関係をインストール
npm install

# 2. 環境変数を設定
cp .env.example .env.local
#   .env.local を開いて ANTHROPIC_API_KEY を設定
#   （https://console.anthropic.com/ で取得できます）

# 3. 開発サーバーを起動
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

## コーチの口調をカスタマイズする

コーチの人格・口調・フィードバックの型は **`lib/persona.ts`** に集約されています。

- `COACH_PERSONA` … コーチの役割・フィードバックの型・観点・トーンの指示
- `FEEDBACK_EXAMPLES` … 実際の過去フィードバックを Few-shot 例として追記すると、より忠実に口調を再現できます

実際のコーチ（みなこさん）が過去に送った LINE のフィードバック文をいくつか `FEEDBACK_EXAMPLES` に貼り付けると、言い回しの再現度が上がります。

## デプロイ

Vercel などの Next.js 対応ホスティングにそのままデプロイできます。環境変数 `ANTHROPIC_API_KEY` を設定してください。

## 注意事項

- フィードバックの栄養・カロリー数値は写真からの推定であり、医療的な診断ではありません。体調に関わる相談は専門家・医療機関へ案内する設計になっています。
- 送信された画像は Claude API に送られてフィードバック生成に使われます。会員さんへの案内・同意取得をご確認ください。
